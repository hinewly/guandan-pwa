# 掼蛋 PWA（guandan-pwa）

DaoBox 家族第 13 个应用：经典掼蛋纸牌竞技（单人 + AI 对手）。

## 玩法

- 四人两两配合：玩家（南）+ AI 队友（北）对抗 AI 东、西两家
- 两副牌 108 张，每人 27 张；级牌从 2 打到 A
- 牌型：单张 / 对子 / 三张 / 三带二 / 顺子 / 连对 / 钢板 / 炸弹 / 同花顺 / 王炸弹
- 头游方升级：单下 +2 级、双下 +3 级；打到 A 获胜即通关
- 简化规则（一期）：无进贡还贡、无逢人配（级牌百搭），后续版本加入

## 技术栈

- 纯前端 PWA（零服务器对战成本）：原生 HTML/CSS/JS
- `rules.js` 规则引擎（牌型判定/比较/出牌生成）· `ai.js` 启发式 AI
- 牌局进度 localStorage 本机存档
- 接入 DaoBox portal 时长体系（游客 15 分/天、注册 30 分/天，邀好友可加时）

## 本地开发

```bash
node server/node-server.mjs   # http://127.0.0.1:8798
```
